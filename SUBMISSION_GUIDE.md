## 🚀 Step-by-Step Instructions

### Step 1: Create Your GitHub Repository
1. Log in to [GitHub](https://github.com/).
2. Click **New Repository**.
3. Set **Repository Name** to exactly:
   ```text
   OIBSIP
   ```
   *(Important: Must be all caps `OIBSIP`. Do not name it `oibsip-tasks` or `oasis-internship`)*.
4. Set visibility to **Public**.
5. Do **NOT** initialize with a README (we already have a complete one).
6. Click **Create repository**.

---

### Step 2: Push This Code to Your GitHub Repository
Open PowerShell or Terminal inside the `OIBSIP` directory:

```bash
# Navigate to the OIBSIP folder
cd "c:\Users\Aditya\OneDrive\Desktop\oasis infobyte\OIBSIP"

# Initialize Git
git init

# Add all project folders, notebooks, scripts, and plots
git add .

# Commit your work
git commit -m "Complete all 5 Data Science internship tasks for Oasis Infobyte SIP"

# Rename branch to main
git branch -M main

# Link your remote GitHub repository (replace YOUR-USERNAME with your actual GitHub username)
git remote add origin https://github.com/YOUR-USERNAME/OIBSIP.git

# Push to GitHub
git push -u origin main
```

---

### Step 3: Record Your Demo Video
> ⚠️ **Strict Requirement from Task List:**  
> The video must begin with a clear **2-second static title card** displaying:
> 1. Your Full Name (`Aditya`)
> 2. Your Assigned Track (`Data Science`)
> 3. The Task Title (e.g., `Task 1: Iris Flower Classification`)

#### How to use the included Title Card Tool:
1. Open [`title_card_generator.html`](title_card_generator.html) in your browser.
2. Select the Task from the dropdown (or type your name).
3. Click **"Enter Fullscreen Display"**.
4. Start your screen recorder (e.g., OBS Studio, Windows Game Bar `Win + G`, or Loom).
5. Keep the title card visible on screen for **2–3 seconds**.
6. Switch over to your browser/VS Code showing your Jupyter Notebook and code running!
7. Walk through the results and charts for 1 to 2 minutes.
8. Stop recording.

*(Refer to [`DEMO_VIDEO_SCRIPT.md`](DEMO_VIDEO_SCRIPT.md) for what to say during the demo!)*

---

### Step 4: Post on LinkedIn
1. Upload your recorded video or a video link to LinkedIn.
2. Tag **Oasis Infobyte** (`@Oasis Infobyte`).
3. Copy-paste the pre-written template from [`LINKEDIN_POST_TEMPLATES.md`](LINKEDIN_POST_TEMPLATES.md).
4. Verify the required hashtag `#oasisinfobyte` is included along with domain hashtags (`#datascience #machinelearning #internship`).

---

### Step 5: Complete Peer Evaluation (Graded Requirement)
1. On LinkedIn, search for the hashtag `#oasisinfobyte`.
2. Find at least **two** other interns from your cohort who posted their demo videos.
3. Watch their video and leave a **substantive, constructive comment** (e.g., engage with their model accuracy, discuss their feature selection, or ask a question about their preprocessing pipeline).
   > *Note: Generic comments like "Great work!" or "Nice job!" do not qualify according to the Oasis Infobyte guidelines.*

---

### Step 6: Submit the Task Submission Form
1. Look for the **Task Submission Form** link sent to your email in the orientation/offer letter.
2. Enter your details:
   - Full Name
   - Email ID
   - Assigned Track: `Data Science`
   - GitHub Repository Link: `https://github.com/<your-username>/OIBSIP`
   - LinkedIn Post Link(s)
3. Submit the form before the deadline.

---

- Evaluations typically take **2 weeks** post-deadline.
- Because you have completed **all 5 tasks** (exceeding the minimum 3 tasks required), you are in the top tier for:
  1. **Internship Completion Certificate**
  2. **Certificate of Merit**
  3. **Letter of Recommendation (LOR)**
  4. **Job / Placement Referral Support**
